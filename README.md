# React02 カレンダーアプリ 授業スライド

ブラウザで動く HTML スライド（1920×1080、105枚）です。

## 見る

- GitHub Pages: `https://<ユーザー名>.github.io/<リポジトリ名>/`
- 特定のスライドを開く: URL の末尾に `#50` のようにスライド番号を付ける
- ローカルで見る: `python3 -m http.server` を実行して http://localhost:8000/ を開く

## 構成

| パス | 内容 |
|---|---|
| `index.html` | スライド本体（全スライドがこの1ファイルに入っている） |
| `deck-stage.js` | スライド表示用コンポーネント |
| `support.js` | `index.html` の読み込み用ランタイム |
| `assets/` | スライドで使う画像 |
| `_ds/` | デザインシステム（色・フォント・アイコン） |
| `.nojekyll` | GitHub Pages で `_ds/` を配信するために必要（消さない） |

## 編集するときの注意

`index.html` をフォーマッター（Prettier など）で整形しないでください。
コード例の行は `white-space: pre` で表示しているため、整形で入る改行やインデントがそのまま画面に出てレイアウトが崩れます。
VS Code では保存時の自動整形（format on save）を、このフォルダでは無効にしておくと安全です。
